# C704 — كارت النهاية

**القسم:** دعوة لإجراء ولوجو ونهايات · **المدة:** 4.5 ثانية · **المقاس:** 1080×1920 (9:16)

شاشة نهاية فيها «تابعنا» وحسابات السوشيال بتدخل ورا بعض وزرار بينبض.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs C704` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
