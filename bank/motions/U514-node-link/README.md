# U514 — توصيل أداتين

**القسم:** واجهات وإشعارات · **المدة:** 4 ثانية · **المقاس:** 1080×1920 (9:16)

كارتين لأداتين بيطلعوا، وخط متقطّع بيترسم بينهم وكبسولة صغيرة (زي MCP) بتجري عليه. لشرح «الأداة دي بتتوصل بدي».

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs U514` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
