# N407 — أعمدة

**القسم:** أرقام وإحصائيات · **المدة:** 3.5 ثانية · **المقاس:** 1080×1920 (9:16)

أعمدة بتطلع ورا بعض بأطوال مختلفة، فوق كل عمود رقمه، وآخر عمود ملوّن.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs N407` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
