# N401 — عدّاد

**القسم:** أرقام وإحصائيات · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

رقم بيعدّ من صفر لحد الرقم اللي عايزه، ويثبت بنطّة، وتحته كلمتين.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs N401` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.

## القيم اللي تتغير (P)
| المفتاح | القيمة الافتراضية |
|---|---|
| `to` | `1000` |
| `prefix` | `""` |
| `suffix` | `"+"` |
| `label` | `"عميل سعيد"` |
