# U515 — كود بيتكتب

**القسم:** واجهات وإشعارات · **المدة:** 5 ثانية · **المقاس:** 1080×1920 (9:16)

شاشة كود زجاج، السطور بتتكتب حرف حرف والمؤشر بيرمش، وفي الآخر بادج ✓ بتنطّ. لما تحب توري إن الـAI بيكتب الكود.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs U515` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
