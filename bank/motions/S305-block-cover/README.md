# S305 — عواميد ألوان

**القسم:** انتقالات · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

عواميد ملوّنة بتطلع ورا بعض تغطي الشاشة، وبعدين تكمّل لفوق ويبان المشهد الجديد.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs S305` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.

| `a` | `"المشهد ١"` |
