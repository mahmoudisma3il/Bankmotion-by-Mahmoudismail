# B803 — حواف بتنبض

**القسم:** خلفيات ومؤثرات · **المدة:** 4 ثانية · **المقاس:** 1080×1920 (9:16)

حواف الشاشة بتغمق وتنوّر على الإيقاع، فالعين تروح للنص.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs B803` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.

| المفتاح | القيمة الافتراضية |

| `beat` | `0.5` |
