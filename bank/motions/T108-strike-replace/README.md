# T108 — شطب وتبديل

**القسم:** كلام وتايبوجرافي · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

الكلمة بتتشطب، وتحتها بتطلع الكلمة الجديدة بخبطة. بتنفع للأسعار أو «بدل ده خد ده».

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs T108` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
