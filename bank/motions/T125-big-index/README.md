# T125 — رقم القسم الضخم

**القسم:** نصوص وتايبوجرافي · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

كلمة صغيرة فوق (ADD-ON) ورقم ضخم «01» بيتقلب لحد ما يثبت، وتحته نقط بتوضح إنت فين في السلسلة.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs T125` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.

## القيم اللي تتغير (P)
| المفتاح | القيمة الافتراضية |
|---|---|
| `label` | `"ADD-ON"` |
| `num` | `1` |
| `total` | `4` |
| `title` | `"يعمل التعليق الصوتي"` |
