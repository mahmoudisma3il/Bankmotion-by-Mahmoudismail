# B808 — أورورا

**القسم:** خلفيات ومؤثرات · **المدة:** 6.6 ثانية · **المقاس:** 1080×1920 (9:16)

شرايط نور ملوّنة زي الشفق القطبي بتتموّج براحة.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs B808` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
