# AGENTS.md (repo root)

The motion bank lives in ONE folder: `bank/` (one page that is updated in place — old + new motions merged; the version label in `bank/bank.config.json` goes v1 → v2 → …).
Follow `bank/AGENTS.md` and resolve codes via `bank/catalog.json`. Codes are permanent: never renumber or delete a motion. `LATEST` contains `bank`.
`v1/` is only a redirect to `bank/` (old links) — don't put content there.

The site (root `index.html`, `site/`, `videos/`) is generated by `node site/build.mjs` from `videos/videos.json` — see `ADDING-VIDEOS.md`.
