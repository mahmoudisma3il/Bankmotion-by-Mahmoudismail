# AGENTS.md (repo root)

This repo keeps every version of the motion bank side by side (`v1/`, `v2/`, …). Always use the latest version — its name is in `LATEST` (currently `v1`).
Then follow `<latest>/AGENTS.md` (resolve codes via `<latest>/catalog.json`). Codes are permanent across versions; never edit older version folders.

The site (root `index.html`, `site/`, `videos/`) is generated by `node site/build.mjs` from `videos/videos.json` — see `ADDING-VIDEOS.md`. It never touches version folders.
