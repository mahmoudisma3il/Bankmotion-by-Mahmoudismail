# P601 — نص ورا الشخص

**القسم:** صور وأشخاص وكاميرا · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

كلمة ضخمة بتطلع من تحت وتقف ورا الشخص (الشخص قدام النص). محتاجة صورة الشخص مقصوصة PNG.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs P601` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
