# U510 — كارت إعلان

**القسم:** واجهات وإشعارات · **المدة:** 3.5 ثانية · **المقاس:** 1080×1920 (9:16)

كارت إعلان/منتج بصورة وعنوان وسعر ومكان، بيطلع لفوق وبعدين بادج «مميز» بيختم عليه.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs U510` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.

## القيم اللي تتغير (P)
| المفتاح | القيمة الافتراضية |
|---|---|
| `title` | `"تويوتا لاندكروزر ٢٠٢٢"` |
| `price` | `"١٢,٥٠٠ د.ك"` |
| `place` | `"الكويت · حولي"` |
| `badge` | `"مميز"` |
