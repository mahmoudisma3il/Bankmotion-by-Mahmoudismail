# N403 — عجلة أرقام

**القسم:** أرقام وبيانات · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

كل رقم بيلف زي ماكينة القمار ويقف على الرقم الصح، رقم ورا رقم.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs N403` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.

## القيم اللي تتغير (P)
| المفتاح | القيمة الافتراضية |
|---|---|
| `value` | `"2026"` |
| `label` | `"سنة البداية"` |
