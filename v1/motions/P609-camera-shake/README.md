# P609 — هزة كاميرا

**القسم:** صور وأشخاص وكاميرا · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

الكادر كله بيتهز هزة قوية مع كلمة صدمة. لأي لحظة مفاجأة.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs P609` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
