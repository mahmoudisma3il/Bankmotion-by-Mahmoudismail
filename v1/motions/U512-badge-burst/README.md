# U512 — بادج خصم

**القسم:** واجهات وإشعارات · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

بادج دايري بأشعة بتلف وراه بيخبط في الشاشة بخصم كبير ويهتز.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs U512` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.

## القيم اللي تتغير (P)
| المفتاح | القيمة الافتراضية |
|---|---|
| `top` | `"خصم"` |
| `value` | `"٥٠٪"` |
| `bottom` | `"لفترة محدودة"` |
