# T123 — سؤال وجواب

**القسم:** نصوص وتايبوجرافي · **المدة:** 4 ثانية · **المقاس:** 1080×1920 (9:16)

سؤال بيظهر وعلامة الاستفهام بتتنطط، وبعدين السؤال يطلع لفوق ويظهر الجواب بلون مميز.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs T123` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
