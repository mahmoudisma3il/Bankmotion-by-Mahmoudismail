# P605 — صور بولارويد

**القسم:** صور وأشخاص وكاميرا · **المدة:** 3.5 ثانية · **المقاس:** 1080×1920 (9:16)

٣ صور بولارويد بتقع فوق بعض بميلات مختلفة وظل، زي ألبوم ذكريات.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs P605` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
