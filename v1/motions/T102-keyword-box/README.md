# T102 — كلمة تسبّق

**القسم:** نصوص وتايبوجرافي · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

الجملة تظهر، وبعدها الكلمة المهمة تتحط في بوكس ملوّن بخبطة. زي «المونتاج صار أسرع».

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs T102` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.

## القيم اللي تتغير (P)
| المفتاح | القيمة الافتراضية |
|---|---|
| `pre` | `"المونتاج صار"` |
| `kw` | `"أسرع"` |
