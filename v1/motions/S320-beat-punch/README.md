# S320 — قطعات على البيت

**القسم:** انتقالات · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

٣ قطعات سريعة على الإيقاع، كل قطعة بزووم خبطة وفلاش صغير. ممتازة مع المزيكا.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs S320` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
