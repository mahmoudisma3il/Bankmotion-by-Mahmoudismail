# C701 — زرار متابعة

**القسم:** دعوة لإجراء ولوجو ونهايات · **المدة:** 3.5 ثانية · **المقاس:** 1080×1920 (9:16)

كارت بروفايل بزرار «متابعة»، الماوس بيضغط عليه فيتحول لـ«تمت المتابعة» بلون تاني.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs C701` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
