# T105 — ماركر فسفوري

**القسم:** نصوص وتايبوجرافي · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

خط ماركر بيترسم ورا العبارة المهمة كأنك بتعلّم عليها بقلم فسفوري.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs T105` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.

## القيم اللي تتغير (P)
| المفتاح | القيمة الافتراضية |
|---|---|
| `pre` | `"السر كله في"` |
| `kw` | `"أول ٣ ثواني"` |
| `color` | `"#FFD84D"` |
