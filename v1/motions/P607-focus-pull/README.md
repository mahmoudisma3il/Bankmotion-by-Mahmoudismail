# P607 — فوكس على الشخص

**القسم:** صور وأشخاص وكاميرا · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

الخلفية بتضبب تدريجيًا والشخص يفضل واضح ويقرب سنة. عزل الشخص عن الخلفية.

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs P607` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.
