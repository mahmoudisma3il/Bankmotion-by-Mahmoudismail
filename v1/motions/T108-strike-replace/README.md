# T108 — شطب واستبدال

**القسم:** نصوص وتايبوجرافي · **المدة:** 3 ثانية · **المقاس:** 1080×1920 (9:16)

كلمة بتتشطب بخط، وتطلع تحتها الكلمة البديلة بخبطة. ممتازة للأسعار أو «بدل كذا».

## الاستخدام
- **معاينة:** افتح `index.html` في المتصفح (بتشتغل لوحدها وتعيد).
- **رندر فيديو:** `node tools/render.mjs T108` من جذر البنك، أو اعتبره HyperFrames composition عادي.
- **تعديل:** غيّر قيم `P` في أول السكريبت.

|---|---|
| `old` | `"ساعتين مونتاج"` |
| `neu` | `"١٠ دقايق"` |
